# Constraint-Guided Human Motion Diffusion — Project Page

Static project page for:

**Constraint-Guided Human Motion Diffusion: Phase-Aware Physical Artifact Reduction toward Long-Horizon Obstacle-Aware Generation**

## Local preview

Open `index.html` directly in a browser, or run a small local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Create a dedicated public repository (for example `constraint-guided-human-motion-page`) and upload the **contents of this folder** so that `index.html` is at the repository root.

In GitHub:

1. `Settings` → `Pages`
2. Source: `Deploy from a branch`
3. Branch: `main`
4. Folder: `/ (root)`
5. Save
